## About SIL OFL 1.1

The SIL Open Font License is a free, open-source license for fonts. It permits:
- **Free use** for any purpose (personal, commercial, educational, etc.)
- **Modification** of the font files
- **Redistribution** with the same license

It requires:
- Retention of the license and copyright notice
- Non-trademark use of the font name (derivatives must be renamed)

For the full license text, see: https://scripts.sil.org/OFL

All fonts in this inventory may be used and modified under these terms.
